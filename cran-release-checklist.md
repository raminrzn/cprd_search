# CRAN release checklist

- [ ] Check the final source tarball on current R and R-devel; record exact
  versions, operating systems, and results in cran-comments.md.
- [ ] Confirm Windows, macOS and Linux checks, including the PDF manual build.
- [ ] Confirm the package name does not collide with current/archived CRAN or
  current Bioconductor packages.
- [ ] Review and merge the preparation pull request.
- [ ] Build the final source tarball using current R and review its contents.
- [ ] Submit that tarball through the CRAN submission form and complete the
  confirmation email sent to ramin.rezaeianzadeh@outlook.com.

Keep the synthetic fixture labeled as fabricated. No real dictionary or patient
data is included. A new-submission NOTE is expected and should be explained;
other significant notes require investigation before submitting.
